about=Draws CAD-style dimension features on the map: linear, aligned, angular, radius, diameter, and leader (callout) dimensions. Each "New Dimension Layer" creates a GeoPackage with a rule-based renderer (a native double-headed QGIS arrow symbol for the dimension line, a thin symbol for extension lines/rays) and a label expression, so styling stays fully editable afterwards through the ordinary Layer Properties panel. Endpoints snap using QGIS's own project snapping settings.
